Поисковый запрос

Для поиска нужен пользовательский VK API token с доступом к группам. Используется токен, сохранённый в настройках проекта «Сайты»; база групп при этом отдельная.

Поиск выполняется через VK API. Сбор участников доступен в разделе «Подписчики». Сообщения отправляются вручную после проверки профиля.
