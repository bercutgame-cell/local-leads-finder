01

Библиотека HTML-шаблонов

Загружай свои шаблоны по категориям

Выбери категорию бизнеса и загрузи свой HTML. При открытии карточки клиента подходящий шаблон будет использоваться для создания отдельной версии сайта. Сам HTML можно редактировать полностью.

Выбери категорию и загрузи HTML-файл.

Переменные для автоматической подстановки: {{company_name}}, {{title}}, {{phone}}, {{email}}, {{address}}, {{website}}, {{description}}, {{button_text}}, {{services_text}}, {{services_html}}. После подстановки ты можешь вручную изменить абсолютно любой участок HTML.

Рабочий процессЗагрузи шаблон → адаптируй HTML под компанию → опубликуй сайт и отправь клиенту постоянную ссылку.

Подключение публикации

Вставь HTTPS-адрес Cloudflare Worker и пароль публикации. Пароль сохраняется в этом браузере на устройстве, чтобы не вводить его при каждом открытии; GitHub-токен находится исключительно в серверном секрете Worker.
