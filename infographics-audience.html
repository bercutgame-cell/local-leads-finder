Источник для сбора

Выбери группу. Для сбора используется пользовательский VK API token из настроек проекта «Сайты».
Сбор будет идти страницами, до завершения или остановки вручную.

Собираются только данные, которые VK API возвращает для авторизованного аккаунта. Закрытые профили и недоступные поля не обходятся. Наличие профиля в базе не гарантирует возможность написать человеку.
