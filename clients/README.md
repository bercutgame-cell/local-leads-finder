# Публикация сайтов клиентов

Каждый готовый сайт размещается в отдельной папке:

`clients/<slug>/index.html`

Дополнительные CSS, JavaScript, изображения и шрифты клиента должны находиться рядом в этой же папке либо подключаться по абсолютным URL.

После коммита и обновления GitHub Pages адрес сайта:

`https://bercutgame-cell.github.io/local-leads-finder/clients/<slug>/`

Не размещайте здесь секреты, пароли, токены или закрытые данные.
