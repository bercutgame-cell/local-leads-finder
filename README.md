# VK Lead Generator

**Версия 0.1 MVP**

Мобильное веб-приложение для поиска публичных бизнес-сообществ ВКонтакте и формирования локальной базы потенциальных клиентов.

## Реализовано
- Поиск сообществ через VK API `groups.search`.
- Поиск по нише, сортировка результатов.
- Отображение названия, URL, ID, числа участников, описания и аватара, если API возвращает эти поля.
- Сохранение выбранных сообществ в локальную базу браузера.
- Защита от повторного добавления, удаление лидов и экспорт CSV.
- Адаптивный интерфейс для iPhone.
- Access token вводится пользователем в поле приложения и не записывается в репозиторий или localStorage.

## Запуск
1. Открой **Settings → Pages**.
2. Выбери **Deploy from a branch → main → /(root)** и сохрани.
3. Открой опубликованный адрес на iPhone.
4. Вставь пользовательский VK API access token, введи нишу и нажми «Найти сообщества».

Клиент вызывает официальный VK API JSONP-метод `groups.search`. Доступность зависит от типа токена, прав приложения и актуальных ограничений VK API.

## Ограничения
Версия 0.1 **не отправляет сообщения**. Она открывает страницу сообщества; пользователь может вручную начать диалог, если сообщество разрешает входящие сообщения.

Перед реализацией отправки необходимо отдельно подтвердить по актуальной документации VK возможность сценария «личный аккаунт → чужое сообщество», допустимый тип токена и разрешения получателя. Автоматические массовые отправки, обход антиспама и имитация ручной активности не реализуются.

## Безопасность
- База хранится в localStorage текущего браузера и не синхронизируется между устройствами.
- Не публикуй access token в README, HTML, issues или коммитах.
- Используй только уместные деловые обращения, соблюдай правила VK и применимое законодательство.
- Проверяй каждое сообщество и сообщение вручную.
