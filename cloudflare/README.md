# LeadScout Cloudflare VK Collector

Этот Worker подключает LeadScout к официальному VK API и ищет публичные сообщества по городу и категории. Используется метод `groups.search` с `city_id`, поэтому результаты ограничиваются городом из справочника VK. Поиск требует **пользовательский VK access token**: согласно актуальной схеме VK API, `groups.search` принимает user token. См. https://github.com/VKCOM/vk-api-schema/blob/master/groups/methods.json

## Развёртывание через Cloudflare Dashboard

1. Открой https://dash.cloudflare.com/ и войди в аккаунт.
2. Перейди в **Workers & Pages → Create → Create Worker**.
3. Создай Worker с именем, например `leadscout-vk-collector`.
4. После создания открой **Edit code**.
5. Замени стартовый код содержимым файла `cloudflare/worker.js` из этого репозитория.
6. Нажми **Deploy**.
7. Открой **Settings → Variables and Secrets → Add**.
8. Выбери тип **Secret**, имя `VK_ACCESS_TOKEN`, значение — свой пользовательский токен VK API. Сохрани и снова нажми Deploy, если интерфейс попросит.
9. Открой Worker URL вида `https://leadscout-vk-collector.<account>.workers.dev`.

## Получение VK-токена

Нужен именно пользовательский токен, потому что `groups.search` в схеме VK API объявлен для типа токена `user`. Получай его через официальную авторизацию VK для собственного приложения и только на официальных страницах VK. Не используй сторонние сайты-генераторы токенов и не отправляй токен в чат, GitHub или поле приложения. Справка VK: https://dev.vk.com/api/access-token

Если VK не позволяет выдать токен для приложения или требует дополнительных проверок, это ограничение VK, а не Cloudflare. Worker не обходит авторизацию.

## Подключение в LeadScout

1. Открой https://bercutgame-cell.github.io/local-leads-finder/
2. В блоке «Автоматический сбор сообществ ВКонтакте» вставь URL Worker (без `/search`).
3. Нажми «Сохранить адрес».
4. Выбери город, категорию и, если нужно, подкатегорию.
5. Нажми «Собрать компании из VK».

Адрес Worker сохраняется только в локальном браузере. Сам токен VK хранится только в Cloudflare Secret.

## Ограничения и качество

- Поиск идёт по публичным сообществам, которые возвращает VK API, и по городскому ID из справочника VK.
- Сообщество не всегда является действующей компанией или физической точкой. Точный адрес, актуальность и принадлежность страницы нужно проверить вручную.
- Не найденный в VK сайт не означает, что у бизнеса нет сайта.
- Worker не читает закрытые сообщества, личные сообщения или приватные профили.
- Telegram и Instagram не подключены к автоматическому сбору: их официальные API не дают универсального бесплатного поиска всех бизнес-страниц. Для них LeadScout оставляет отдельные поисковые ссылки и ручное подтверждение.
- Worker использует бесплатный тариф Cloudflare в пределах действующих лимитов; актуальные лимиты: https://developers.cloudflare.com/workers/platform/limits/
- Встроенное ограничение частоты — до 8 запросов в минуту на IP (в рамках одного экземпляра Worker).

## API

- `GET /health` — проверка доступности Worker.
- `POST /search` — тело JSON: `{"city":"Липецк","category":"beauty","subcategory":"Парикмахерские"}`.

Токен не передаётся из браузера. Worker проверяет Origin GitHub Pages и вызывает VK API на серверной стороне.
